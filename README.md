# Loan Analysis Dashboard 📊

## 🔷 Project Overview

This project is a Power BI dashboard created to analyze loan approval patterns based on applicant details such as income, education, CIBIL score, and assets.

## 🔷 Features

* KPI cards (Loan Amount, Income, CIBIL Score)
* Donut chart for loan status
* Bar chart for education analysis
* Treemap for asset distribution
* Interactive slicers for filtering

## 🔷 Tools Used

* Power BI
* Excel

## 🔷 Insights

* Higher CIBIL score increases loan approval chances
* Applicants with higher assets are more likely to get loans
* Education level impacts loan distribution

## 🔷 Files Included

* Loan dataset (Excel)
* Power BI dashboard (.pbix)
